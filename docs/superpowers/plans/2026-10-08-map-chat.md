# Map Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bottom chat panel to `template.html` that answers questions about the map's own data with Qwen3 running through WebLLM on the local GPU, and offers to navigate to the entity it describes.

**Architecture:** Pure logic (document index, lexical ranking, context assembly, answer parsing, navigation rules) lives in a `CHAT CORE` region of `template.html` with no DOM access, evaluated in Node by `chat.test.js` the same way `check.js` evaluates the data region. A second `CHAT` module owns the panel, the WebLLM runtime and the navigation handshake, and talks to the existing app only through `window.__arch`. Spec: `docs/superpowers/specs/2026-10-08-map-chat-design.md`.

**Tech Stack:** Vanilla JS in one HTML file; `@mlc-ai/web-llm` 0.2.85 via dynamic `import()` from jsDelivr; `node:test` for tests (Node 18+, no dependencies).

---

## File structure

| File | Change | Responsibility |
|---|---|---|
| `template.html` | Modify CSS block (after `/* hint + tooltip */`) | Chat button and panel styles |
| `template.html` | Modify body (after `#hint`) | Chat button and panel markup |
| `template.html` | Modify APP module (`updateInsets`, keydown guard, `window.__arch`) | Bottom inset hook, ignore keys typed in the chat, expose `focusZone`, `cur`, `ZONE`, `setBottomInset` |
| `template.html` | Add `CHAT CORE` region after the APP module | `ChatCore`: `buildDocs`, `rank`, `buildContext`, `parseAnswer`, `resolveTarget`, `isAffirmative`, `factsAnswer`, `suggestQuestions`, `buildMessages` |
| `template.html` | Add `CHAT` module after CHAT CORE | Panel UI, Runtime (WebGPU check, WebLLM load/stream), asking, offers, "yes" handling |
| `chat.test.js` | Create | Node tests for CHAT CORE against the Acme example |
| `README.md` | Modify | "Chat" section: requirements, sizes, privacy |

Script order inside `template.html` after this plan: Engine → DATA DSL → ARCHITECTURE DATA → APP → CHAT CORE → CHAT.

```js
/* ======================= BEGIN CHAT CORE (pure — no DOM, no network; tested by chat.test.js) =======================
   Retrieval over the ARCHITECTURE DATA, prompt context assembly, answer parsing and the navigation
   rules used by the chat panel below. Keep this region free of browser APIs so Node can evaluate it.
   ==================================================================================================================== */
const ChatCore = (() => {
  const paras = d => (Array.isArray(d) ? d : d ? [d] : []);
  const plain = s => String(s == null ? '' : s).replace(/\*\*([^*]+)\*\*/g, '$1').replace(/`([^`]+)`/g, '$1');
  const clip = (s, n) => { s = String(s == null ? '' : s).replace(/\s+/g, ' ').trim(); return s.length > n ? s.slice(0, n - 1).trimEnd() + '…' : s; };
  const estimateTokens = s => Math.ceil(String(s == null ? '' : s).length / 3.6);

  /* ---- documents ---- */
  function buildDocs(M) {
    const { META, CATS, PROVIDERS, KINDS, ZONES, NODES, EDGES, FLOWS, INSIDE } = M;
    const docs = [], byId = new Map();
    const add = d => { docs.push(d); byId.set(d.id, d); return d; };
    const catLabel = c => (CATS && CATS[c] && CATS[c].label) || c || '';
    const provLabel = p => (PROVIDERS && PROVIDERS[p] && PROVIDERS[p].label) || '';
    const zoneName = (zones, id) => { const z = zones.find(q => q.id === id); return z ? z.name : ''; };
    const nodeDoc = (n, view, zones, viewTitle) => {
      const district = zoneName(zones, n.zone), facts = (n.facts || []).map(f => plain(f[0]) + ': ' + plain(f[1]));
      const does = (n.does || []).map(plain), tech = (n.tech || []).map(plain), desc = paras(n.desc).map(plain);
      const text = [n.name, n.tag, n.blurb, ...desc, ...does, ...facts, ...tech, ...(n.paths || []), n.notes, provLabel(n.prov), catLabel(n.cat), district, viewTitle].filter(Boolean).map(plain).join(' ');
      return add({ id: n.id, kind: 'node', view, name: n.name, aliases: [n.tag, n.blurb].filter(Boolean).map(plain).join(' '), text, height: n.h || 0,
        catLabel: catLabel(n.cat), provLabel: n.prov && n.prov !== 'own' ? provLabel(n.prov) : '', district, blurb: plain(n.blurb), desc, does, tech, facts, inside: !!(INSIDE && INSIDE[n.id]), conns: [], neigh: new Set() });
    };
    add({ id: 'about', kind: 'about', view: 'root', name: META.title, aliases: [META.tagline, META.brand].filter(Boolean).join(' '),
      text: [META.title, META.tagline, ...paras(META.intro)].map(plain).join(' '), card: clip(`${META.title}: ${plain(META.tagline)} ${paras(META.intro).map(plain).join(' ')}`, 600) });
    const zoneDoc = (z, view, nodes, viewTitle) => add({ id: z.id, kind: 'zone', view, name: z.name, aliases: plain(z.tag), text: [z.name, z.tag, ...paras(z.desc), catLabel(z.cat), viewTitle, 'district'].filter(Boolean).map(plain).join(' '),
      desc: paras(z.desc).map(plain), members: nodes.filter(n => n.zone === z.id).map(n => n.name) });
    ZONES.forEach(z => zoneDoc(z, 'root', NODES, ''));
    NODES.forEach(n => nodeDoc(n, 'root', ZONES, ''));
    for (const v of Object.values(INSIDE || {})) { v.zones.forEach(z => zoneDoc(z, v.id, v.nodes, v.title)); v.nodes.forEach(n => nodeDoc(n, v.id, v.zones, v.title)); }
    const edgeDocs = (edges, view) => edges.forEach(e => {
      const a = byId.get(e.a), b = byId.get(e.b); if (!a || !b) return;
      const kind = (KINDS && KINDS[e.kind] && KINDS[e.kind].label) || e.kind;
      const line = `${a.name} → ${b.name} (${kind}${e.label ? ', ' + plain(e.label) : ''})${e.d ? ': ' + clip(plain(e.d), 120) : ''}`;
      if (a.kind === 'node') { a.conns.push(line); a.neigh.add(b.id); }
      if (b.kind === 'node' && b !== a) { b.conns.push(line); b.neigh.add(a.id); }
      add({ id: `edge:${e.a}>${e.b}`, kind: 'edge', view, name: `${a.name} → ${b.name}`, aliases: [e.label, kind].filter(Boolean).map(plain).join(' '),
        text: [a.name, b.name, e.label, kind, e.d].filter(Boolean).map(plain).join(' '), ends: [e.a, e.b], card: line });
    });
    edgeDocs(EDGES, 'root');
    for (const v of Object.values(INSIDE || {})) edgeDocs(v.edges, v.id);
    FLOWS.forEach(f => {
      const steps = f.steps.map((s, i) => { const a = byId.get(s[0]), b = byId.get(s[1]); return `${i + 1}. ${a ? a.name : s[0]} → ${b ? b.name : s[1]}: ${plain(s[3])}`; });
      add({ id: f.id, kind: 'flow', view: 'root', name: f.name, aliases: plain(f.blurb), text: [f.name, f.blurb, ...steps, 'guided flow scenario walkthrough'].map(plain).join(' '), steps, blurb: plain(f.blurb) });
    });
    docs.forEach(d => { if (!d.card) d.card = makeCard(d); d.short = makeShort(d); });
    return { docs, byId };
  }
  function makeCard(d) {
    if (d.kind === 'node') {
      let s = `${d.id} | ${d.name} | ${d.district} | ${d.catLabel}${d.provLabel ? ' / ' + d.provLabel : ''} | ${clip([d.blurb, ...d.desc].join(' '), 260)}`;
      if (d.does.length) s += ' Does: ' + clip(d.does.join('; '), 160) + '.';
      if (d.facts.length) s += ' ' + clip(d.facts.join('; '), 120) + '.';
      if (d.tech.length) s += ' Tech: ' + d.tech.join(', ') + '.';
      if (d.inside) s += ' Has an inside view.';
      if (d.conns.length) s += ' Connections: ' + clip(d.conns.join('; '), 320);
      return s;
    }
    if (d.kind === 'zone') return `${d.id} | ${d.name} (district) | ${clip(d.desc.join(' '), 200)} Contains: ${d.members.join(', ')}.`;
    if (d.kind === 'flow') return `${d.id} | ${d.name} (guided flow) | ${d.blurb} Steps: ${clip(d.steps.join(' '), 420)}`;
    return d.card || '';
  }
  function makeShort(d) {
    if (d.kind === 'node') return `${d.id} | ${d.name} | ${d.district} | ${clip(d.blurb || d.desc[0] || '', 110)}`;
    return clip(d.card, 160);
  }

  return { buildDocs, estimateTokens };
})();
/* ======================= END CHAT CORE ======================= */
```

  /* ---- tokens ---- */
  const STOP = new Set('a an the and or of to in on for with by at from is are was were be been being do does did it its this that these those what which who whom how where when why tell me about show explain describe please can could you i we my our your into than then there their they them any all some more most much very also just like get give us used use'.split(' '));

  const stem = w => (w.length > 4 && /ies$/.test(w) ? w.slice(0, -3) + 'y' : w.length > 3 && /s$/.test(w) && !/ss$/.test(w) ? w.slice(0, -1) : w);

  /* ---- ranking ---- */
  function rank(docs, question, state) {
    state = state || {};
    const q = String(question == null ? '' : question).toLowerCase(), qt = terms(question);
    const scored = [];
    for (const d of docs) {
      if (!d._t) d._t = { name: new Set(terms(d.name)), alias: new Set(terms(d.aliases)), text: new Set(terms(d.text)) };
      let s = 0;
      for (const w of qt) { if (d._t.name.has(w)) s += 5; else if (d._t.alias.has(w)) s += 3; else if (d._t.text.has(w)) s += 1; }
      const nm = d.name.toLowerCase();
      if (nm.length > 2 && q.includes(nm)) s += 8;
      if (d.kind !== 'about' && d.kind !== 'edge' && q.includes(d.id.toLowerCase())) s += 6;
      if (s === 0) continue;
      if (state.selected === d.id) s += 3;
      if (state.prevTarget === d.id) s += 4;
      if (state.view && state.view !== 'root' && d.view === state.view) s += 1;
      scored.push({ doc: d, score: s });
    }
    if (!scored.length) {
      const prev = state.prevTarget && docs.find(d => d.id === state.prevTarget);
      if (prev) scored.push({ doc: prev, score: 1 });
      const sel = state.selected && state.selected !== state.prevTarget && docs.find(d => d.id === state.selected);
      if (sel) scored.push({ doc: sel, score: 1 });
    }
    scored.sort((a, b) => b.score - a.score || (a.doc.kind === 'edge') - (b.doc.kind === 'edge') || a.doc.name.localeCompare(b.doc.name));
    return scored;
  }

```js
  /* ---- prompt context ---- */
  function buildContext(ranked, byId, budget) {
    budget = budget || 450;
    const lines = [], used = new Set(), candidates = [];
    let tokens = 0;
    const push = (d, card) => {
      if (used.has(d.id)) return false;
      const t = estimateTokens(card);
      if (lines.length && tokens + t > budget) return false;
      used.add(d.id); lines.push(card); tokens += t; return true;
    };
    const about = byId.get('about'); if (about) push(about, about.card);
    const navigable = d => d.kind === 'node' || d.kind === 'zone' || d.kind === 'flow';
    for (const r of ranked.filter(x => x.doc.kind !== 'about').slice(0, 6)) {
      const d = r.doc;
      if (d.kind === 'edge') {
        for (const id of d.ends) { const n = byId.get(id); if (n && navigable(n) && push(n, n.card)) candidates.push({ doc: n, score: r.score }); }
        continue;
      }
      if (navigable(d) && push(d, d.card)) candidates.push({ doc: d, score: r.score });
    }
    const topDoc = candidates[0] && candidates[0].doc;
    if (topDoc && topDoc.kind === 'node') for (const id of topDoc.neigh) { const n = byId.get(id); if (n) push(n, n.short); }
    return { context: lines.join('\n'), candidates, tokens };
  }
```

## Chat about the map

The bottom-centre button opens a chat that answers questions about the map's own data and offers to take you to the system, district or flow it describes. It runs a small language model on your GPU inside the browser through [WebLLM](https://github.com/mlc-ai/web-llm); nothing is sent anywhere.

- Speed: on an Apple M2 Pro the default model answers in about 3 seconds; the Fast tier in about 2.
- Privacy: the runtime comes from jsDelivr and the weights from Hugging Face; questions and the map data never leave the browser.
